# EcoTech

> **Pequenas atitudes. Grandes transformações.**

Plataforma web que conecta tecnologia, natureza e pessoas para transformar a sustentabilidade em benefício coletivo: incentivar a reciclagem, conectar pessoas e locais de coleta, oferecer recompensas e construir uma cidade mais sustentável.

Stack atual: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4. Backend, autenticação e mapa ainda não decididos (ver [`docs/process/decisions.md`](docs/process/decisions.md)).

## Começando

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```
